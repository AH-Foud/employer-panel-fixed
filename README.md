# پنل مدیریت کارفرما — نسخه اصلاح‌شده (v2.2)

ربات بله + پنل مدیریت تحت وب برای ارتباط کاربران با کارفرما با قابلیت SOP (پاسخ خودکار).

## 🔧 تغییرات در این نسخه

- **🐛 رفع باگ `__BASE_PATH__`**: مشکل لینک‌های API در حالت پروکسی Nginx برطرف شد. قبلاً مقدار `BASE` در جاوااسکریپت همیشه خالی می‌ماند و هیچ لینکی کار نمی‌کرد.
- **پایداری بهتر**: هندلینگ خطاها بهبود یافته.

## نصب سریع

```bash
bash <(curl -s https://raw.githubusercontent.com/AH-Foud/employer-panel-fixed/main/install.sh)
```

نیازمندی‌ها: Ubuntu 20+/Debian 11+، دسترسی root، پورت 80 باز (برای SSL)

## نصب دستی

```bash
pip3 install -r requirements.txt
python3 run.py
```

## بعد از نصب

1. فایل `config.py` را ویرایش کنید — توکن ربات (`BOT_TOKEN`) و آیدی ادمین (`ADMIN_ID`) را تنظیم کنید
2. با دستور `karpanel` منوی مدیریت را باز کنید
3. پنل تحت وب در آدرس نمایش داده شده قابل دسترسی است

## امکانات

- ارسال پیام کاربر ← کارفرما با فوروارد خودکار
- تشخیص SOP بر اساس کلمات کلیدی و پاسخ خودکار
- مدیریت کارفرمایان با لینک دعوت
- پنل مدیریت تحت وب با آنالیتیکس و مدیریت کاربران
- دیتابیس SQLite (بدون نیاز به تنظیمات اضافی)
- SSL خودکار با Let's Encrypt
- دستور `karpanel` برای مدیریت
